## FT8 Ham Radio Mode version 2.00

# These set of programs extract data from an Excel file.
The excel file was created by downloading text file from Ham Radio Deluxe using power query to extract the columns required

This program analysis FT8 RST sent and RST received along with propagation parameters A index, K index and SFI

These python scripts have been created for a magazine article and for my own interest on how well my RF systam works

Each script has an explaination

## Features

-To create a different data file all data is extracted from FT8_data_functions
-All plots are in each script

## Requirements
Python 3.6+
